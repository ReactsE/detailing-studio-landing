# Шаблон сайта для детейлинг-студии

Одностраничный сайт для студии автодетейлинга, кузовного ремонта или оклейки. Написан на чистом HTML5, CSS3 и Vanilla JS без внешних тяжелых библиотек.

---

### Основные компоненты и функционал

- Темная тема с неоновыми акцентами и кастомной типографикой (шрифт Unbounded для заголовков, Manrope для текста).
- Интерактивный слайдер сравнения состояния кузова с ползунком.
- Встроенные интерактивные элементы интерфейса: 3D-наклон карточек при наведении курсора, магнитные кнопки, аккордеон с частыми вопросами и автослайдер отзывов.
- Адаптивная верстка под экраны смартфонов с плавающей нижней панелью быстрых действий (звонок и запись).
- Быстрый переход в WhatsApp и прямые вызовы по клику на телефон.
