# 🚗 Премиум лендинг для детейлинг-студии

Современный, ультрабыстрый и конверсионный одностраничный сайт для студии автодетейлинга, полировки и оклейки.

---

### ✨ Особенности и фишки

- 🏎️ **Стиль:** Премиальная тёмная тема (`#05070d`) с неоновыми бирюзовыми акцентами (`#18c8ff`) и шрифтом **Unbounded**.
- 🎚️ **Слайдер «До / После»:** Интерактивное сравнение состояния кузова (до полировки / после полировки керамикой) с ползунком.
- ⚡ **Легковесность:** Чистый HTML5, CSS3 и Vanilla JS — **никаких тяжелых библиотек**, моментальная загрузка.
- 📱 **100% Mobile Ready:** Адаптирован под смартфоны и планшеты.
- 💬 **Кнопки мессенджеров:** Быстрая запись через WhatsApp и прямой звонок.
- 🧩 **Интерактив:** 3D-тилт карточек за мышкой, магнитные кнопки, анимированные счётчики статистики, аккордеон FAQ и авто-слайдер отзывов.

---

### 🚀 Быстрый старт

1. Склонируйте репозиторий или скачайте архив.
2. Откройте `index.html` в любом браузере.
